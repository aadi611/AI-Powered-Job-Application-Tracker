# 🚀 Quick Start Guide - AI Job Tracker

## ⚡ 30-Second Setup

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Create `.env` file:**
   ```
   OPENAI_API_KEY=sk-your-api-key-here
   FLASK_SECRET_KEY=any-random-string
   FLASK_ENV=development
   ```
   Get API key: https://platform.openai.com/api-keys

3. **Run the app:**
   ```bash
   python app.py
   ```

4. **Open browser:**
   ```
   http://localhost:5000
   ```

---

## 🎯 Quick Actions

### Add Application with AI (10 seconds)
1. Click **"AI Job Parser"** (purple button)
2. Paste job description
3. Click **"Parse with AI"**
4. Review → **"Add Application"**

### View Application Details
1. **Click any application card**
2. Navigate tabs: Overview, Details, Notes, Timeline

### Generate Follow-up Email
1. Open application details (click card)
2. Click **"Generate Follow-up Email"** (green button)
3. Review timing recommendation
4. **Copy** subject and body
5. Personalize and send

### View AI Insights
1. Go to **Dashboard**
2. AI Insights section shows automatically (with 3+ apps)
3. Review insights and recommendations
4. Click **"Refresh"** after adding more apps

## 💡 Pro Tips

### Maximize AI Parser Accuracy
✅ Paste **complete** job posting (not just title)  
✅ Include salary if it's in the posting  
✅ Copy from original source (LinkedIn, Indeed, etc.)  
❌ Don't paste just a few lines

### Get Better Follow-up Emails
✅ Wait **5-7 days** before generating (optimal timing)  
✅ **Personalize** AI email before sending  
✅ Add specific research about the company  
❌ Don't send AI email verbatim

### Make Insights More Valuable
✅ Add **diverse applications** (different sources)  
✅ **Update statuses** promptly (Applied → Interview → Offer)  
✅ Check insights **weekly** to spot trends  
❌ Don't delete old applications (they provide valuable data)

## 🔧 Troubleshooting

### "AI parsing failed"
→ Paste more complete job description  
→ Check internet connection

### "Failed to generate follow-up email"
→ Refresh page and try again  
→ Check OpenAI API key in `.env`

### "Failed to load insights"
→ Need at least 3 applications  
→ Check API key and internet

### Charts not showing
→ Refresh page  
→ Check browser console for errors
